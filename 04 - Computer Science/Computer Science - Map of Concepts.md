## :LiPin:in: Suggested Practice Loop

1. Read [[00 - C++ Reference/Complete C++ Reference for Competitive Programming|Complete C++ Reference]] to refresh syntax, pointers, and STL containers.
2. Read one lesson and type every code example yourself.
3. Solve **3–5 easy problems** (e.g. from [CSES Introductory Problems](https://cses.fi/problemset)) only using that idea.
4. Write down mistakes, then solve one problem again without looking.
5. Join contests (AtCoder ABC or Codeforces Div 3/4) for learning—not for rank. Upsolve one problem after every contest.
6. Do not rush into advanced topics. Strong basics, pattern recognition, and calm debugging win more problems.

> [!TIP] Starting point
> Begin with [[00 - C++ Reference/Complete C++ Reference for Competitive Programming|Complete C++ Reference]], then [[01 - C++ Foundations & Algorithmic Paradigms/Lesson 01 - C++ Foundations & Contest Setup|Lesson 01]] and [[01 - C++ Foundations & Algorithmic Paradigms/Lesson 02 - Complexity, Correctness & Debugging|Lesson 02]]. Do not skip complexity: it tells you which solutions are possible.
