## 1. Artificial Intelligence (AI) & Machine Learning

**Artificial Intelligence (AI)** is the branch of computer science focused on building smart machines capable of performing tasks that typically require human intelligence.

### Machine Learning Categories:
1. **Supervised Learning**: Model trained on **labeled datasets** (Input-Output pairs).
2. **Unsupervised Learning**: Model finds hidden patterns/clusters in **unlabeled data**.
3. **Reinforcement Learning**: Model learns optimal actions through **trial-and-error rewards and penalties**.

### Key AI Subfields:
- **Natural Language Processing (NLP)**: Enables computers to understand human spoken and written text.
- **Computer Vision**: Analysis and understanding of digital images and video.
- **Intelligent Software Agents**: Autonomous software entities that observe their environment and act to achieve specific goals.

---
## 2. Cloud Computing

Cloud Computing delivers computing services (servers, storage, databases, networking, software) over the Internet ("the cloud").

### Service Models:
- **IaaS (Infrastructure as a Service)**: Rent raw computing infrastructure (Virtual Machines, Storage, Networks); e.g., AWS EC2, Google Compute Engine.
- **PaaS (Platform as a Service)**: Environment for developers to build and deploy applications without managing underlying infrastructure; e.g., Heroku, Google App Engine.
- **SaaS (Software as a Service)**: Ready-to-use software delivered over the internet; e.g., Google Workspace, Microsoft 365.

### Deployment Models:
- **Public Cloud**: Owned and operated by third-party providers, shared across public users.
- **Private Cloud**: Infrastructure operated solely for a single organization.
- **Hybrid Cloud**: Combines public and private cloud environments.

---
## 3. Emerging Computing Paradigms

- **Quantum Computing**: Uses quantum mechanical phenomena (**Qubits**, Superposition, Entanglement) to solve complex calculations exponentially faster than classical supercomputers.
- **Grid Computing**: Combines distributed computer resources from multiple locations to reach a common computational goal.
- **Ubiquitous / Pervasive Computing**: Computing integrated seamlessly into everyday objects everywhere.

---
## 4. Cyber Security & Threats

- **Malware Types**:
  - **Virus**: Self-replicating code attached to host files.
  - **Worm**: Standalone self-replicating malware that spreads across networks automatically.
  - **Trojan Horse**: Disguised as legitimate software to deceive users.
  - **Ransomware**: Encrypts user files and demands payment for decryption key.
- **Cyber Attacks**:
  - **Phishing**: Fraudulent emails designed to steal sensitive passwords/credit cards.
  - **DDoS (Distributed Denial of Service)**: Floods target server with overwhelming traffic from botnets, rendering it unavailable.
- **Defense Mechanisms**: Firewalls, Encryption (Symmetric/Asymmetric), Multi-Factor Authentication (MFA), Antivirus software.

---
## 5. Computer Ethics & Green Computing

- **Intellectual Property Rights (IPR)**: Legal rights protecting creations of the mind (Copyright, Patents, Trademarks, Creative Commons licenses).
- **Software Piracy**: Unauthorized copying, distribution, or commercial use of copyrighted software.
- **Green Computing**: Environmentally sustainable use of computers and IT resources.
  - Practices: Energy-efficient hardware design, server virtualization, proper E-Waste recycling, reduced power consumption.
